# 十二周年#021：第二收入赚10万元（截止：2026年10月3日）

目标：在 2026 年 10 月 3 日前，通过第二收入累计赚 100000 元。

默认报价：

- 主服务：一人公司利润体检冲刺
- 首 4 单价格：1299 元/单
- 恢复价：1999 元/单
- 降阶产品：499 元迷你诊断
- 收款目标：4 单主服务 = 5196 元

服务边界：本项目只提供经营财务诊断、利润测算、报价优化和现金流整理建议，不提供税务申报、代理记账、审计、法律、投资或理财建议。

## 每日动作

1. 新增 50 个有效触达对象。
2. 记录每个人的状态、渠道、痛点、下一步和跟进日期。
3. 对有回复的人发送免费「利润漏洞自查清单」。
4. 对痛点明确的人推进 1299 元利润体检。
5. 每天复盘回复率、深聊率、报价率、付款率。

## 4 天校准线

- 至少完成 200 个触达。
- 至少 15 个回复。
- 至少 1 个付款，或 3 个明确问价。

如果未达标，立即执行：

- 主服务限时改为 999 元。
- 目标改为 5 单主服务 + 1 单 499 元迷你诊断。
- 私信话术从「财务诊断」改成「帮你找出利润漏洞和报价问题」。

## 网页版 app

直接打开 `index.html` 即可使用，不需要安装依赖或启动服务器。

核心功能：

1. 四个报价拥有各自的独立工作区，任一时刻只展示当前报价的解决路径、控制点、资料和交付边界。
2. 数据表单与测算结果随当前报价切换，共享已有经营数据，并保留每个报价的工作进度。
3. 话术库按报价模块自动切换，支持复制私信开场、筛选问题、成交话术、风险逆转和边界说明。
4. 三天循环任务自动按日期显示当前执行日。
5. 线索作战表支持新增线索，并按痛点推荐对应报价。

## 今日启动顺序

1. 打开工作簿，先在「Dashboard」查看目标。
2. 在「CRM」录入今天 50 个潜在客户。
3. 复制 `assets/03_outreach_scripts.md` 中的冷触达模板，开始发送。
4. 有人回复后，发送 `assets/02_profit_leak_checklist.md`。
5. 有人愿意深聊后，发送 `assets/04_intake_questions.md` 的 3 个筛选问题。
